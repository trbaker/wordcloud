# Dynamic wordclouds from ArcGIS feature services

<a href="mappyhalloween.html">Mappy Halloween Word Cloud</a><br>
The "Happy Halloween" version was created to supported the Mappy Halloween project at https://storymaps.arcgis.com/stories/e9035a73ceaa47318ce681341def5f4a.  It uses a Halloween color theme and pulls one specific column from one specific feature service.

<a href="main.html">General word cloud</a><br>
The general word cloud tool can be customized to point at any public ArcGIS Online feature service and one specified  field. Color themes can be selected.  A share button allows dynamic word clouds to be embedded in story maps or other environments.
